# SlackHack
Slack bot made for HackClub Stardance.<br>
The bot is running on Hack Club Nest, so you can access it directly from [Slack channel](https://hackclub.enterprise.slack.com/archives/C0CAD53DPB8).

## Available commands:
to use commands, type /slackhack-[command] in the [channel](https://hackclub.enterprise.slack.com/archives/C0CAD53DPB8).
- /slackhack-hello - Greets the user.
- /slackhack-ping - Checks the bot's latency.
- /slackhack-help - Display help list.
- /slackhack-weather - Tells the weather.
- /slackhack-quote - Tells a quote.
- /slackhack-joke - Tells a joke.

## APIs used:
- Open-Meteo for weather data.
- Zen Quotes for quote command.
- Official Jokes for joke command.

## AI usage:
- ChatGPT for explaining and fixing problems.
- Github Copilot for code completion.
